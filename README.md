# Tallis: public pages

The public web pages for the Tallis Android app by Vyoma Studios, served by GitHub Pages:

- `/`: about Tallis and contact details
- `/privacy/`: the privacy policy (the URL to give Google Play)
- `/delete-data/`: how to delete your data

These are static HTML pages with no scripts, cookies or analytics.

The privacy policy comes from `docs/legal/PRIVACY_POLICY.md` in the app repository. Change both together, before shipping any app version that changes how data is handled.
